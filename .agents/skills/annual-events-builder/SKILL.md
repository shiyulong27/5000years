# 🛠️ 【十丘】年度重大事件补全技能 (annual-events-builder)

> 当用户要求“补充/补全某一年（如 2022年、2021年、1960年等任意年份）的中外重大事件”时，自动激活本 Skill，按标准 SOP 全流程无缝执行。

---

## 📋 适用场景与触发词

- **触发口令**：“帮我补充 2022 年大事记”、“补全 2021 年数据”、“提炼 1960 年中国与世界重大事件” 等。

---

## ⚙️ 6 步标准自动化流程 (Standard Operating Procedure)

### 步骤 1：抓取官方权威锚点与补充来源
1. **中国事件骨架**：
   - **1978 年及以后年份**：使用 `search_web` 搜索 `site:news.cn <目标年份> 国内十大新闻`，提取新华社权威报道。
   - **1978 年以前年份**：使用 `search_web` 搜索 `"中华人民共和国大事记 <目标年份>"` 或 `"中共中央党史大事记 <目标年份>"` 作为中国史权威骨架。
2. **世界事件骨架**：搜索 `site:news.cn <目标年份> 国际十大新闻` 或 `"世界历史大事记 <目标年份>"`。
3. **维基百科补充**：使用 `read_url_content` 读取英文/中文维基百科年度页（如 `https://en.wikipedia.org/wiki/<目标年份>`），补查十大之外的重磅突破。

### 步骤 2：事实核查与 5 大领域强制交叉核验（防遗漏机制）
1. 精确核对事件的**时间（`date`）**、地点与关键数据，禁止任何推测性或模糊措辞。
2. **5 大领域强制 checklist（防止重大遗漏）**：
   - ① **政治/党史**：中央重要会议、党内重大决策、宪法/法律通过、重大人事变动
   - ② **经济/工业/农业**：重大工业会战（如油田/钢铁）、大型水利/交通基建、农业政策调整、金融贸易
   - ③ **科技/航天/国防**：导弹/核武器/卫星试射、重大科学发明（如激光器/计算机）、国防科技
   - ④ **外交/国际关系**：国家建交、重大国际条约/协定、国际组织成立（如非盟/OPEC/欧盟）、地缘政局
   - ⑤ **文化/体育/民生/灾害**：重大体育赛事突破、流行文化/艺术符号、特大自然灾害（地震/洪水）、民生重大转折
3. 评定 **重要度等级 (`importance: 1-5`)**（对应前端 1~5 颗黄色 ⭐）：
   - `5 级 (历史转折 ⭐⭐⭐⭐⭐)`：划时代重大转折（挂 👑 历史转折徽章，一年仅 3-5 件）。
   - `4 级 (重大事件 ⭐⭐⭐⭐)`：重大政策、航天突破、国际盛会等。
   - `3 级 (常态事件 ⭐⭐⭐)`：常规重要节点。
4. 匹配分类 (`category`) 与标签 (`tags`)：
   - 科技/航天/体育/卫生/艺术 ➔ `文化`
   - 战争/军事冲突 ➔ `战争`
   - 外交/机构改革/党建/会议 ➔ `政治`
   - 金融/贸易/宏观/工业/农业 ➔ `经济`
   - 地震/洪水/核污染/气候 ➔ `灾害`
   - **常用标签**：`[航天, 科技, AI, 深潜, 科考, 外交, 军事, 芯片, 电影, 体育, 法律, 改革, 民生, 教育, 关税, 贸易, 金融, 灾害, 气候]`

### 步骤 3：提交候选清单供用户审阅
在正式修改文件前，将整理好的 **“<目标年份>年中国与世界重大事件候选清单表格”** 发给用户确认。

### 步骤 4：追加写入 YAML 数据文件
用户确认后，按规范分别追加至文件末尾：
- 中国事件 ➔ `data/events/xiandai.yaml`
- 世界事件 ➔ `data/world/modern.yaml`

```yaml
- id: cn-<slug>-<yyyymm>
  date: "YYYY-MM-DD"
  title: 事件标题
  category: 政治
  importance: 5
  summary: 事实描述摘要
  confidence: 确定
  tags: [标签1, 标签2]
  sources: [新华网, 维基百科]
```

### 步骤 5：自动生成前端专页与路由注册
1. **生成专页**：创建 `src/pages/<目标年份>.astro`（参考 `2024.astro` 结构，实现 1 月至 12 月 3 栏升序展现与分类筛选）。
2. **注册中轴交互**：
   - 在 `src/components/Timeline.astro` 的 `summaryYears` 集中加入 `<目标年份>`。
   - 在 `src/components/AxisCell.astro` 的 `hasSummary` 集中加入 `<目标年份>`，开启中轴**点击跳转**与 **[概览] ⇄ [详情] 动态模式切换**。
3. **注册十丘首页入口**：在 `src/pages/index.astro` 的 `quick-year-links` 中加入 `<目标年份>年大事记 ➔` 芯片按钮。
4. **生成跟踪看板**：在根目录创建 `<目标年份>_events_plan.md` 记载看板。

### 步骤 6：运行全套门禁校验
依次运行以下三步自动化命令，确保 0 错误：
```bash
npm run validate  # 强校验数据 Schema 格式
npm test          # 运行单元测试
npm run build     # 验证全量 260+ 静态页面编译生成
```
