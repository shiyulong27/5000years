# 🛠️ 【十丘】年度重大事件补全技能 (annual-events-builder)

> 当用户要求“补充/补全某一年（如 2022年、2021年、1960年等任意年份）的中外重大事件”时，自动激活本 Skill，按 8 大来源原则与标准 SOP 全流程无缝执行。

---

## 📜 数据来源与防遗漏 8 大原则

1. **主选候选来源**：
   - **所有年份**：中国与世界事件均以新华社（站内搜索及年度十大新闻）和中英文维基百科年度页（如 `https://en.wikipedia.org/wiki/<目标年份>`）为主要候选来源。
   - **1978 年以前**：新华社公网早期数字化资料不足时，如实记录来源缺失；可选用《人民日报》历史数据库、中共中央党史研究室或中央档案馆官方史料补充，不强制扩充事件数量。
2. **正文完整读取**：
   使用当前环境可用的网页读取工具完整读取可访问的来源正文，必要时分页或分段读取；严禁仅凭搜索引擎摘要（Snippet）断言事实或生成内容。
3. **按领域站内补充检索**：
   在新华社站内按 6 大领域进行分类补充检索：**政治、经济工业、外交军事、科技、文化体育、灾害**；早期年份可同时检索人民网历史资料。
4. **如实记录来源状况**：
   找不到新华社年度十大新闻或相关正文时，在报告中如实记录“未找到”，不得为了凑数强制改用非权威来源扩充事件。
5. **专业文献与事实核验**：
   党史、政府部门、国际组织和专业机构（如国防科工局、NASA、CAS、OPEC等）资料主要用于事实核验；对于 1978 年以前的国防科技与重大工业突破解密档案，权威专业机构文献亦可作为收录凭据。
6. **领域 CheckList 定性防护**：
   6 大领域 CheckList 只用于检查是否有重大领域遗漏，不强制要求每个领域每年必须有事件。
7. **品质至上（宁缺毋滥）**：
   事件数量不设最低或最高限制，不得为了凑数降级或放宽重要度（`importance`）标准。
8. **透明化追踪（Audit Trail）**：
   任务完成后必须在报告中明确说明实际读取了哪些新华社、人民网和维基百科页面正文，以及哪些来源无法找到。

## ⚙️ 6 步标准自动化流程 (Standard Operating Procedure)

### 步骤 1：抓取官方权威锚点与补充来源
1. **中国事件骨架**：
   - 搜索 `site:news.cn <目标年份> 国内十大新闻`，读取可访问的新华社报道正文。
   - 1978 年以前找不到新华社资料时如实记录；可选查阅人民日报历史数据库或官方党史、档案资料，不把补充来源变成数量要求。
2. **世界事件骨架**：搜索 `site:news.cn <目标年份> 国际十大新闻`，读取可访问的新华社报道正文；不使用来源不明的“世界历史大事记”网页作为候选依据。
3. **维基百科补充**：完整读取中文和英文维基百科年度页，补查新华社年度报道之外的重磅事件。

### 步骤 2：事实核查与 6 大领域站内补充检索
1. 精确核对事件的**时间（`date`）**、地点与关键数据，必须读取正文，禁止推测或模糊措辞。
2. **6 大领域定性防护 Checklist（防止漏项）**：
   - ① **政治**：中央重要会议、党内重大决策、宪法/法律通过、重大人事变动
   - ② **经济工业**：重大工业会战（如油田/钢铁）、大型水利/交通基建、农业政策调整、金融贸易
   - ③ **外交军事**：国家建交、重大国际条约/协定、国际组织成立（如非盟/OPEC/欧盟）、国防导弹/战争冲突
   - ④ **科技**：科学技术突破（如激光器/计算机/农学）、重大科研成果
   - ⑤ **文化体育**：重大体育赛事突破、航天探索/深潜科考、流行文化/艺术符号、民生转折
   - ⑥ **灾害**：特大自然灾害（地震/洪水/风暴/气候）
3. 评定 **重要度等级 (`importance: 1-5`)**（对应前端 1~5 颗黄色 ⭐）：
   - `5 级 (历史转折 ⭐⭐⭐⭐⭐)`：划时代重大转折（挂 👑 历史转折徽章，一年仅 3-5 件）。
   - `4 级 (重大事件 ⭐⭐⭐⭐)`：重大政策、航天突破、国际盛会等。
   - `3 级 (常态事件 ⭐⭐⭐)`：常规重要节点。
4. 匹配分类 (`category`) 与标签 (`tags`)：
   - 科技/航天/体育/卫生/艺术 ➔ `文化`
   - 战争/军事冲突 ➔ `战争`
   - 外交/机构改革/党建/会议 ➔ `政治`
   - 金融/贸易/宏观/工业/农业 ➔ `经济`
   - 地震/洪水/核污染/气候 ➔ `灾害`

### 步骤 3：提交候选清单与读取源审计报告
在正式修改文件前，整理 **“<目标年份>年中国与世界重大事件候选清单”**，并附上实际读取的网页与未找到来源说明发给用户确认。

### 步骤 4：追加写入 YAML 数据文件
用户确认后，按规范分别追加至文件末尾：
- 中国事件 ➔ `data/events/xiandai.yaml`
- 世界事件 ➔ `data/world/modern.yaml`

```yaml
- id: cn-<slug>-<yyyymm>
  date: "YYYY-MM-DD"
  title: 事件标题
  category: 政治
  importance: 5
  summary: 事实描述摘要
  confidence: 确定
  tags: [标签1, 标签2]
  sources: [新华网, 中文维基百科, 英文维基百科]
```

### 步骤 5：自动生成前端专页与路由注册
1. **生成专页**：创建 `src/pages/<目标年份>.astro`（参考 `2024.astro` 结构）。
2. **注册中轴交互**：在 `Timeline.astro` 和 `AxisCell.astro` 中加入 `<目标年份>`，开启概览切换。
3. **注册十丘首页入口**：在 `src/pages/index.astro` 中加入快捷链接。

### 步骤 6：运行全套门禁校验
```bash
npm run validate  # 强校验数据 Schema 格式
npm test          # 运行单元测试
```
