# 固定书目基线

## 当前操作基线

本项目用《上下五千年（上、中、下）》作为**读者预期和篇目覆盖索引**，不是史实权威来源。

| 字段 | 值 |
|---|---|
| 书名 | 《上下五千年（上、中、下）》 |
| 作者 | 林汉达、曹余章 |
| 出版社 | 少年儿童出版社 |
| 出版时间 | 1988 年 9 月 |
| 页数 | 1261 页 |
| 书目记录 | [豆瓣 API 1055429](https://m.douban.com/rexxar/api/v2/book/1055429) |
| 人工可读页 | [豆瓣书目页 1055429](https://book.douban.com/subject/1055429/) |
| 记录内容 | API 返回作者、出版社、出版年月、页数和完整目录；目录为前言、篇号 1–262、本书大事年表、后记 |

### 为什么固定 1988 年版

- 2026-08-18 实际读取 API 返回 HTTP 200；`catalog` 共 263 行，目标段第 1–26 篇连续，且可直接复核原题。
- 1991 年同社记录 [1012561](https://m.douban.com/rexxar/api/v2/book/1012561) 同样为 1261 页，但公开目录只列前 13 篇及省略号，无法支撑本项目第 14 篇以后的逐篇映射。
- 1988 版是本项目的**操作基线**，不是“最权威历史版本”。若未来取得出版社、国家图书馆或带 ISBN 的馆藏一手记录，应新增版本记录、比较目录，并经审计决策后再切换，不能静默替换。

## 来源分层

1. **历史事实**：传世原始文献、出土材料、官方档案/博物馆资料、可靠学术研究。
2. **辅助核验**：权威工具书、学术机构页面、可追溯的百科条目。
3. **覆盖索引**：本书固定版本的书目记录和篇名。

本书的作者说明和故事叙事可帮助发现读者熟悉的主题，但不能单独证明人物生卒、精确年份、动机、对话或传奇细节。报告中必须把“书中篇名”与“史料支持”分栏记录。

## 记录规则

- 每次审计记录书目 URL、API/页面访问日期、关键元数据和目标目录截取范围。
- 只保存篇名和书目信息，不复制正文，不下载受版权保护的内容。
- API、书目页不可访问时记录失败，不用搜索摘要或其他版本目录替代。
- 版本冲突时并列记录作者、出版社、出版年月、页数、ISBN/馆藏号（若有）和目录差异；未完成比较前不得声称版本相同。
- 目录来源只能决定“覆盖发现”，不能决定 `confidence`。置信度和争议必须由独立史料核验。

## 已知限制

- 当前 1988 年记录没有返回 ISBN；不能把缺失 ISBN 当成“无 ISBN”或自行补写。
- 国家图书馆旧 OPAC 在 2026-08-18 本环境连接失败；不能声称已取得国家图书馆馆藏确认。
- Open Library 的相关工作记录只有不完整的 1984 年版本信息，不作为本项目基线。
