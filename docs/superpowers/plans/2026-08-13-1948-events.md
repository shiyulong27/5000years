# 1948 年重大事件补全实施计划

**目标：** 按已确认清单补入 1948 年 7 条中国事件、10 条世界事件，并接入独立年份页及主时间线入口。

**数据设计：** 中国事件追加到 `data/events/minguo.yaml`，世界事件追加到 `data/world/modern.yaml`。所有事件使用现有统一字段：`id`、`date`、`title`、`category`、`importance`、`summary`、`confidence`、`tags`、`sources`。来源优先采用新华网、政府或国际组织等权威来源，并以第二来源交叉核验。

**页面设计：** 新建薄页面 `src/pages/1948.astro`，复用 `AnnualEventsPage`；在 `Timeline.astro` 的 `summaryYears` 和 `AxisCell.astro` 的 `hasSummary` 中注册 1948。

**验证：** 先添加失败的 1948 年回归测试，锁定数量、字段、重要事件 ID、专页和两个入口；实现后运行该测试、`npm run validate`、配图专项测试和全量 `npm test`。不执行仓库明确禁止的 `npm run build`。
