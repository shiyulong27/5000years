# 1989 年重大事件补全设计

## 目标

补全 1989 年中国与世界重大事件数据，生成独立年份专页并注册首页和主时间线入口，使 1989 年与现有 1988、1990 年专页保持一致的数据密度、交互体验和验证标准。

## 范围

- 向 `data/events/xiandai.yaml` 追加 8 条中国事件。
- 向 `data/world/modern.yaml` 追加 10 条世界事件。
- 创建 `src/pages/1989.astro`，提供按月份升序的世界—中轴—中国三栏时间线及分类筛选。
- 在 `src/components/Timeline.astro` 和 `src/components/AxisCell.astro` 注册 1989 年概览/详情切换。
- 在 `src/pages/index.astro` 增加 1989 年快捷入口。
- 创建 `1989_events_plan.md`，记录候选事件、来源和验收状态。
- 增加自动化测试，覆盖数据存在性、字段要求、专页和路由注册。

不引入新组件、不调整现有视觉设计，也不重构与年度补全无关的代码。

## 数据设计

每条事件包含 `id`、`date`、`title`、`category`、`importance`、`summary`、`confidence`、`tags` 和 `sources`。事件 ID 使用 `cn-<slug>-<yyyymm>` 或 `w-<slug>-<yyyymm>`，日期使用 ISO 日期字符串；摘要控制在三句话以内，并注明可核查的时间、主体与历史影响。

## 来源与核验

中国事件优先使用新华网、中国政府网、全国人大网、中国青少年发展基金会及相关官方机构资料；世界事件优先使用新华社历史资料、联合国或相关政府和机构资料。中英文维基百科的 1989 年度页及事件条目用于补充与交叉核验，不作为唯一来源。

核验时确认事件日期、主体、地点和关键结果。若权威来源在日期或数字上存在差异，采用官方法律文本、机构纪念资料或事件发生地政府资料，并在摘要中避免有争议的精确数字。

## 页面与交互

`src/pages/1989.astro` 复用 `src/pages/1988.astro` 的结构：加载全部 YAML 数据后筛选 1989 年事件，按月份分组并按日期升序排列。世界事件位于左栏，中国事件位于右栏，中轴显示月份；分类按钮只展示该年实际使用的分类，并在浏览器端切换事件可见性。

主时间线的 `summaryYears` 与 `hasSummary` 都加入 `1989`，使年份节点能够在概览和详情模式间切换并跳转至 `/1989/`。首页快捷年份区域加入“1989年大事记”入口。

## 测试与验收

先增加一个针对 1989 年补全结果的自动化测试，并确认它在实现前因缺少数据、专页或路由而失败。实现后运行该测试并确认通过，再依次执行：

1. `npm run validate`
2. `npm test`
3. `npm run build`
4. 启动本地开发服务器并用浏览器访问 `/5000years/1989/`，检查页面渲染、分类筛选和返回链接。

验收条件为 YAML Schema 校验无错误、全量测试无失败、静态构建成功，且 1989 年专页可以正常浏览和筛选。
