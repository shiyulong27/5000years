# 2025 年五级重大事件配图设计

## 目标

为 2025 年全部五级重大事件补充真实、稳定、可追溯的纪实配图。范围包括中国事件 5 条、世界事件 7 条，共 12 条。现有事件标题、日期、摘要、重要度和分类保持不变。

## 事件范围

### 中国事件

- DeepSeek-R1 发布震动全球 AI 格局
- 上海合作组织天津峰会举行
- 纪念抗战胜利 80 周年大会与阅兵
- 中共二十届四中全会审议“十五五”规划建议
- 福建舰正式入列，中国进入三航母时代

### 世界事件

- 加沙三阶段停火协议生效
- 特朗普宣誓就任第 47 任美国总统
- 美国推出“对等关税”引发全球市场震荡
- 教宗方济各逝世，良十四世继任
- 以色列突袭伊朗，“十二日战争”爆发
- 加沙停火协议达成，和平计划启动
- 联合国迎来成立 80 周年

## 图片策略

优先选择事件发生时的真实新闻或官方纪实图片。来源优先级如下：

1. 事件相关官方机构公开媒体资源，例如新华社、联合国、白宫、梵蒂冈等。
2. Wikimedia Commons 中许可清晰、与事件直接相关的图片。
3. 若没有可本地保存的事件现场图片，使用与事件主体直接相关且时间相近的官方图片，并在图注中准确说明画面内容，避免暗示其为事件现场。

不使用 AI 生成图片，不把示意图描述为新闻现场，不采用来源或许可不明的网络图片。

## 文件与数据结构

图片保存到 `public/images/events/2025/`。文件名使用小写英文与连字符，并与事件含义对应。优先保存为 WebP；若转换会损害透明度、兼容性或来源信息，则保留 JPG/PNG。

每张图片应控制在适合网页加载的尺寸，长边原则上不超过 1600 像素，并在不明显影响视觉质量的前提下压缩。

对应 YAML 事件增加以下结构：

```yaml
image:
  url: "/images/events/2025/example.webp"
  caption: "准确描述画面内容及必要的时间、地点信息"
```

图片许可与出处记录在 `docs/image-sources/2025.md`，每项包含事件 ID、本地文件、原始页面、作者或机构、许可证或使用依据，以及访问日期。YAML 图注保持面向读者的简洁描述，不塞入冗长许可文本。

## 失败处理

- 若某事件暂时找不到许可清晰且事实匹配的图片，不用来源不明图片替代；在来源清单中记录缺口并继续寻找可靠来源。
- 下载后检查文件确为有效图片，而不是 HTML 错误页或缩略图占位。
- 图片路径、扩展名与 YAML 引用必须完全一致。
- 同一画面仅在确实同时代表两个事件时复用；默认每个事件使用独立图片。

## 验证

完成后执行：

1. 检查 12 条五级事件均包含有效 `image.url` 与非空 `caption`。
2. 检查所有本地图片存在、可读取且大小合理。
3. 运行 `npm run validate`。
4. 运行 `npm test`。
5. 运行 `npm run build`。
6. 抽查 2025 年页面，确认图片加载、图注与卡片布局正常。

## 非目标

- 不为四级及以下事件配图。
- 不修改 2025 年事件事实内容或重要度。
- 不改造 `EventCard.astro` 的图片展示组件。
- 不扩展到其他年份。
