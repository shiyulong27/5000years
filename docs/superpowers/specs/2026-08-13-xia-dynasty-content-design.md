# 夏朝内容完善设计

## 目标

完善夏朝详情与时间线内容：补齐传统文献所载的君主世系，为夏代君主增加可见的“帝王”标签，扩充关键事件与非君主重要人物，并为适合的事件配置有明确出处的图片。

夏代缺少同时代自证文字，具体世系、人物、事件与年代存在明显争议。本次补充必须区分传统文献叙事、考古证据和后世附会，不把推定年代或传说表述为已核实史实。

## 范围

- 补齐 `data/rulers/xia.yaml` 中传统世系所载的十七位夏代君主。
- 为全部夏代君主增加 `tags: [帝王]`，并在详情页世系表中显示标签徽章。
- 在 `data/events/pre-qin.yaml` 中补充夏朝关键事件。
- 在 `data/figures.yaml` 中补充夏代非君主重要人物；君主不在人物表重复收录。
- 为部分重点事件增加本地图片、图片说明与来源信息。
- 增加针对夏朝数据、图片和标签展示的自动化测试。

不调整其他朝代数据，不重构与夏朝内容无关的组件，也不处理工作区中已有的近现代事件及图片改动。

按传统文献世系收录以下十七位君主：

1. 禹

6. 少康
7. 杼

9. 芒
10. 泄
11. 不降
12. 扃
13. 廑
14. 孔甲
15. 皋
16. 发
17. 桀

禹标记为开国君主；启在备注中明确为首位世袭君主；桀标记为末代君主。全部记录增加 `tags: [帝王]`、`confidence: 有争议` 和具体的 `dispute` 说明。

年代沿用项目现有的夏商周断代工程时间框架，以便在时间线上连续展示。缺乏可靠依据的个人在位起止年均视为展示所需的推定值，不暗示其已经得到考古或同时代文字证实。若不同文献的世系、在位顺序或年数冲突，在争议说明中概括主要分歧。

## 世系标签展示

`src/components/RulerTable.astro` 增加“标签”列。存在 `tags` 时逐项渲染紧凑徽章；没有标签的旧记录显示为空，不要求同步修改其他朝代数据。

该字段只承担展示和未来检索所需的分类，不改变 `role` 的语义。`role: founder` 与 `role: last` 仍分别驱动开国、末代信息展示。

## 重要事件

围绕夏朝兴衰主线补充约 8—12 条事件，候选范围包括：

- 大禹治水与夏的奠基
- 启确立世袭及有扈氏之战
- 太康失国
- 后羿代夏
- 寒浞篡权
- 少康中兴
- 杼时期的对外扩张
- 孔甲时期的统治危机
- 桀失国与鸣条之战

实施时先检查已有的“大禹治水”“夏朝建立”“商汤灭夏”，避免重复事件；必要时订正标题、摘要、标签和来源。只保留足以解释王朝制度转变、权力中断、中兴与灭亡的节点，不把大量神怪故事加入主时间线。

每条新增或修订事件必须包含 `id`、`date`、`title`、`category`、`tags`、`importance`、`summary`、`confidence` 和来源信息。日期无法确证时采用项目允许的推定年份，并通过 `confidence` 与 `dispute` 明示不确定性。

## 重要人物

人物表只补充非君主人物，避免与世系表重复。候选范围为鲧、伯益、有扈氏首领、后羿、寒浞、女艾、靡、关龙逄、妹喜与商汤。

最终收录需满足两个条件：人物对夏朝主线具有明确作用，且可以提供足够的传统文献或考古研究依据。人物真实性、生卒年代或身份存在争议时，使用 `confidence` 与 `dispute` 说明；后世文学塑造不得写成确定史实。人物 `field` 继续使用项目现有枚举，不新增领域类型。

## 图片策略

图片按以下优先级选择：

1. 权威考古机构、博物馆或正式出版资料中的遗址、器物照片。
2. 可核实作者、年代、馆藏和授权状态的后世绘画或人物画像。
3. 无法满足前两项时，该事件不配图。

优先考虑二里头遗址、宫殿基址、出土器物等能够说明夏代考古背景的资料。考古图像不得直接写成“夏王某人遗物”，除非来源本身支持这一归属。使用后世图像时，图片说明必须明确标注“后世绘画”“后世想象图”或实际创作年代，避免产生同时代写真的误解。

图片存放于 `public/images/events/xia/`。事件使用现有 `image` 对象保存站内路径和说明；来源、作者、馆藏与许可信息按项目现有图片来源记录方式保留。只为来源明确且能帮助理解的重点事件配图，不要求每条事件都有图片。

## 来源与核验

资料优先级为：

1. 考古发掘报告、权威博物馆和考古机构资料。
2. 《史记·夏本纪》《尚书》《左传》《竹书纪年》等传统文献。
3. 可靠的现代研究、工具书和机构性历史资料。

涉及十七王名单和顺序时，以传统世系为收录对象，不以此证明夏朝及各君主均为信史。涉及年代、战争、迁都和人物行为时进行交叉核验；来源冲突则并列说明，不能通过无依据的精确数字消除争议。

## 测试与验收

先增加针对性测试，再修改实现。测试至少覆盖：

- 夏代十七王齐全且顺序正确。
- 禹、启、桀分别具备开国、首位世袭、末代说明。
- 所有夏代君主均含“帝王”标签。
- 世系表能够渲染标签，并兼容无标签的其他朝代记录。
- 选定的关键事件与非君主重要人物存在且字段完整。
- YAML 引用的本地事件图片真实存在。

实现后运行数据校验、相关单元测试、全量测试以及仓库已有的 lint、类型或 Astro 检查。遵守项目约束，不执行 `npm run build`。修改后检查 `git diff`、UTF-8 编码、BOM 和换行符，确认没有中文乱码、无关格式变化或其他工作区改动混入。

## 验收结果

夏朝详情页应显示完整传统世系，禹、启、桀的身份说明清楚，十七位君主均带可见的“帝王”徽章；大事区能够呈现夏朝建立、权力中断、中兴和灭亡等关键节点；人物层包含有依据的非君主重要人物；配图均能正常加载且不会把考古关联或后世图像误述为同时代事实。所有相关自动化校验通过。
