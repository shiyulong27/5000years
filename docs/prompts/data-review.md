# 历史数据审查提示词

供外部 AI（如 ChatGPT、Claude、文心一言等）使用的审查提示词，用于交叉验证本项目的历史数据准确性。

---

## 使用方式

1. 将待审查的 YAML 文件内容复制给 AI
2. 附上下面对应类型的提示词
3. AI 会逐条核对并列出问题

---

## 提示词 A：中国历史事件审查

```
你是一位历史学者，正在审校「上下五千年」项目的中国历史事件数据。

以下是一份 YAML 格式的历史事件列表。每条记录包含：
- id: 事件标识符
- date: 日期（"-0202" = 公元前202年，"0208-11" = 公元208年11月）
- title: 事件标题
- desc: 事件描述
- dynasty: 所属朝代
- importance: 重要性（里程碑/重大/一般/背景）
- confidence: 可信度（确定/存疑/有争议/传说）
- tags: 分类标签

请逐条核对以下方面，**只列出有问题或需商榷的条目**：

### 核对维度

1. **年代准确性**
   - 日期是否与主流史料一致
   - 学界有分歧的（如张骞出使西域前139 vs 前138），说明各家观点

2. **史实描述**
   - 事件描述是否准确
   - 是否有明显错误或误导性表述

3. **可信度标注**
   - confidence 标注是否恰当
   - 学界有争议却标"确定"的需指出
   - 史料扎实却标"存疑"的也需说明

4. **重要性评级**
   - importance 评级是否合理
   - 明显高估或低估的需指出

5. **时代归属**
   - dynasty 字段是否正确
   - 事件时间是否落在该朝代区间内

### 输出格式

每个问题一段，格式：

```
条目id | 问题类型 | 说明 | 建议
```

示例：

```
zhangqian-138bc | 年代争议 | 张骞首次出使西域，《史记》《汉书》记载略有出入，前139年与前138年均有学者支持 | 建议标注 confidence: 有争议，或在 desc 中说明年份存疑

cailun-paper | 可信度偏高 | 蔡伦改进造纸术是史实，但"发明"纸张的说法学界已修正（西汉已有植物纤维纸） | 建议 desc 改为"改进造纸术"，confidence 保持"确定"

chibi-208 | 描述不完整 | 赤壁之战的战略意义（奠定三国鼎立）未在 desc 中体现 | 建议补充"奠定三足鼎立格局"
```

### 特别说明

- 对学界共识的条目，无需输出"正确"或"确认"
- 对存在多种说法的，列出主要观点，不判对错
- 上古传说（夏以前）的年代本就模糊，只要标注恰当（confidence: 传说）即可
- 精确到日的古代日期（如"0220-12-11"）需特别留意，涉及农历公历换算，易出错

---

待审查数据：

[在这里粘贴 YAML 文件内容]
```

## 提示词 B：君主世系审查

```
你是一位历史学者，正在审校「上下五千年」项目的君主世系数据。

以下是一份 YAML 格式的君主列表。每条记录包含：
- id: 君主标识符
- dynasty: 所属朝代
- temple_name: 庙号
- name: 本名
- reign_start / reign_end: 在位起止年份
- era_names: 年号（数组）
- note: 备注

请逐条核对以下方面，**只列出有问题或需商榷的条目**：

### 核对维度

1. **在位时间**
   - reign_start 和 reign_end 是否准确
   - 与史料记载是否一致

2. **庙号与本名**
   - temple_name 是否正确（注意追谥、庙号、谥号的区别）
   - name 字段的姓名是否准确

3. **年号**
   - era_names 列表是否完整
   - 年号名称是否准确

4. **朝代归属**
   - dynasty 字段是否正确
   - 在位时间是否落在该朝代区间内

5. **世系完整性**
   - 同一朝代内，君主之间是否有明显缺口（>20年）
   - 缺口是否合理（如东汉只录开国与末代）

### 输出格式

每个问题一段，格式：

```
条目id | 问题类型 | 说明 | 建议
```

示例：

```
han-guangwu | 在位时间有误 | 光武帝刘秀在位至 57 年去世，而非 57 年退位 | 建议 reign_end 保持 0057，但需明确这是去世年而非退位年

wei-wendi | 年号遗漏 | 曹丕除黄初外，还有黄龙年号（一说为伪造） | 如确有其事，建议补充；如存疑，可在 note 中说明

jin-yuandi | 朝代归属争议 | 司马睿 317 年称帝时东晋已建立，dynasty 应为"东晋"而非"晋" | 确认 dynasty 字段为 dong-jin
```

### 特别说明

- 本项目只录代表性君主（如开国、中兴、末代），缺口属正常
- 庙号、谥号、年号的异体字、简化字问题，以通行写法为准
- 在位时间以即位年至去世年为准（除非明确禅让或退位）

- id: 事件标识符
- date: 日期
- title: 事件标题
- region: 地区（欧洲/中东/南亚/东亚/非洲/美洲等）
- importance: 重要性
- confidence: 可信度

请逐条核对以下方面，**只列出有问题或需商榷的条目**：

### 核对维度

   - 特别留意公元前后、世纪换算

   - 跨地区事件的归属是否恰当

```

## 审查原则

1. **只挑错，不确认**——无问题的条目不输出
2. **列出争议，不判对错**——学界有分歧的如实说明各方观点
3. **简洁输出**——每条问题控制在 100 字以内
4. **结构化**——严格按照「条目id | 问题类型 | 说明 | 建议」格式
