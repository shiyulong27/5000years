## A1 时代边界与分期规则（TASK-009）

分期用于统计、筛选与审计分组；**不改变** `related_dynasties` 的多朝代标注。边界与 `data/dynasties.yaml` 现有区间对齐：

| 分期编号 | 名称 | 区间 | 与 dynasties.yaml 对齐说明 |
|---|---|---|---|
| P1 | 先秦 | ～前 221 | 含上古传说时代、夏商周、春秋战国（shanggu/xia/shang/zhou） |
| P2 | 秦汉 | 前 221 – 公元 219 | qin + han（含新莽、更始） |
| P3 | 魏晋南北朝 | 220 – 580 | 三国（自曹丕代汉起）+ 两晋南朝北朝 |
| P4 | 隋唐五代 | 581 – 959 | sui + tang + wudai 及十国 |
| P5 | 宋辽夏金 | 960 – 1270 | song（两宋）+ liao + xixia + jin1115 + 大理等 |
| P6 | 元明清（帝制晚期） | 1271 – 1839 | yuan + ming + qing 前中期；蒙古汗国时期（1206–1270）人物暂归本期并标注 |
| P7 | 近代 | 1840 – 1948 | 鸦片战争至新中国成立前，含民国（minguo） |
| P8 | 现代 | 1949 – | 中华人民共和国 |

### 归属判定规则

1. **主时期唯一**：每个人物只归入一个主时期，用于统计与筛选默认值。
2. **判定优先级**：主要成就完成期 > 活跃高峰期 > 卒年所在期（仅前两项不可考时使用）。
3. **跨期人物**：`related_dynasties` 保留全部相关朝代；年谱事件按各自年份挂接对应分期。
4. **1840–1912 双重归属期**：主要历史作用在于近代变革的人物（如林则徐、李鸿章、张之洞）主时期归近代；以传统王朝治理为主要事迹者归元明清。
5. **政权并存期**（宋辽夏金、魏晋南北朝）：人物按其效忠/活动政权归入同一分期内统计，不以汉族政权为默认视角。
6. **传说时代人物**（盘古、黄帝、尧舜禹等）：仅在有信史讨论价值时以「传说/考古争议」标签进入轻量索引，不得进入全景详卷冒充信史。

## A2 收录矩阵：对象类型与特殊群体规则（TASK-009）

| 对象类型 | 收录决定 | 规则与边界 |
|---|---|---|
| 政治/帝王 | 纳入 | 君主身份由 `rulers/` 体系承载生平位次；figures 只收有跨领域成就或独立解释链价值者（如李煜、赵佶类）。纯治理型君主一般不重复建档 |
| 军事 | 纳入 | 战功人物需至少一条可考战役/制度贡献；演义虚构战绩不得作为依据 |
| 思想 | 纳入 | 含宗教思想家；教义阐释须区分历史事实与信仰内部叙述 |
| 文学 | 纳入 | 本专题核心；诗人词人优先，兼收散文、戏曲、小说名家 |
| 科技 | 纳入 | 当前仅 8 人，为重点补强领域（祖冲之、沈括、徐光启、宋应星等为高优候选） |
| 艺术 | 纳入 | 书法、绘画、音乐；当前仅 5 人，重点补强（颜真卿、吴道子、张择端等为候选） |
| 女性 | 纳入，不设配额 | 不因性别降低证据标准，也不因性别抬高知名度门槛；每期审计必须显式检查女性代表覆盖（当前 173 人中女性极少，属已知偏差） |
| 少数民族/少数民族政权人物 | 纳入 | 辽金元清及诸政权的非汉人物与汉人物同等标准；族属仅在可靠依据时记录，不做推断 |
| 宗教人物 | 纳入 | 法显、玄奘、鉴真、八思巴等；神异传说须标记为传说层 |
| 地方名家 | 暂缓详卷 | 影响超出地方或具独特解释链价值者方可进 T2；否则最多轻量索引 |
| 海外华人 | 暂缓 | 仅在与中华历史进程直接相关且有可靠传记资料时纳入（如容闳类已收录） |
| 外国来华人物 | 有限纳入 | 仅当其活动构成中国史叙事必要环节（如马可·波罗），以「关联人物」身份进轻量索引，不建全景详卷 |
| 负面人物 | 纳入，评价分层 | 秦桧、贾似道、和珅等按史实收录；评价引用须呈现历代语境变化，不采用单一定性骂名作事实陈述 |
| 在世人物 | **暂缓详卷（DEC-006）** | 首期详卷不含在世人物；基础索引可含已核实公开信息。隐私、评价中立性与资料更新责任的完整规则在 TASK-013 前定稿，在此之前现代人物止步于索引层 |
| 并称群组（唐宋八大家等） | 作为标签 | 群组是 `tags` 维度，不是收录单位；成员各自按个体标准评估 |
| 虚构/半虚构人物（花木兰等） | 严格隔离 | 仅在现有数据已存在时保留并强制 `legend` 标记；新增一律不收 |

### 不纳入清单（明确排除）

- 仅存在于演义、评书、影视中的虚构人物；
- 无可靠一手或学术二手来源支撑的传说人物新档案；
- 与中国历史无直接关联的纯外国人物。

## A6 来源、版权、图片与地图许可登记规范（TASK-011）

### S1 Source ID 与书目字段

每个来源登记为可复用 ID，格式 `src-{类型缩写}-{序号}`（如 `src-book-001`、`src-hist-001`、`src-web-001`）。必填字段：

```yaml
sources:
  src-hist-001:
    type: 原始文献 | 出土材料 | 官方档案/博物馆 | 学术研究 | 工具书 | 网络权威页面
    title: 旧唐书·卷二百上
    author_or_org: 后晋·刘昫等
    edition_or_url: 中华书局点校本 1975 / https://...
    access_date: 2026-08-25        # 网络来源必填
    pub_date: ""                   # 出版/发布时间，未知则留空并注明
    isbn_or_id: ""                 # 有则填，无则留空，不得编造
    notes: 引用范围与页码
```

规则：
- 网络来源必须记录访问日期；失效链接不删除，改 `status: 失效` 并注明最后有效日期与替代来源。
- 搜索摘要、聚合百科、AI 生成内容不得单独作为 `type: 原始文献/学术研究` 登记。
- 古籍原文优先标注通行整理本版本；无整理本时可引通行本并注明底本情况。

### S2 版权与展示策略（三级）

| 展示级别 | 定义 | 允许的内容示例 |
|---|---|---|
| full | 可全文展示 | 公版古籍原文（作者卒年超 50 年且底本本身公版） |
| excerpt | 仅限短摘录 + 出处 | 现代学术著作、注释、译文的少量引用（合理使用边界内） |
| none | 不可复制展示 | 现代整章译文、付费数据库内容、影视剧照、博物馆藏品图（未获许可） |

规则：
- 古典作品进入公版 ≠ 现代整理本、注释、译文进入公版；二者权利状态分开登记。
- 每条 `works/reception/media` 条目必须携带 `source_ids` 与展示级别；缺登记的条目校验时报错或警告（TASK-002 落地）。
- 首期媒体策略（回应 ISSUE-005 与未决问题 3）：**图片/地图默认采用「纯文本 + 自制图形」降级方案**；仅当资源满足以下全部条件才入库：明确开放许可（公有领域/CC0/CC-BY 等）、许可凭证链接、署名要求可满足。不确定的一律不入库。

### S3 登记示例（合法 vs 受限）

合法示例：

```yaml
- work_id: jing-ye-si
  title: 静夜思
  text_display: full            # 唐诗原文公版
  source_ids: [src-antho-001]   # 通行整理本《全唐诗》中华书局版（仅作版本出处）
```

受限示例：

```yaml
- reception_id: libai-modern-bio
  title: 某现代李白评传观点摘引
  quote: "……"                  # ≤200 字，注明页码
  text_display: excerpt         # 现代研究著作，仅限短摘录
  source_ids: [src-acad-014]
  rights_note: 受版权保护，禁止整段转载
```

### S4 坐标与地图数据登记

- 历史地名坐标必须记录：现代对应地、坐标精度（市县级/乡镇级/推定）、坐标来源（权威 GIS 数据/文献推定）与 `inferred: true/false`。
- 推定路线、纪念地不得与确证到访混用字段；渲染层据此区分样式并在文本降级中说明（TASK-004 验收项）。
- 人物足迹优先引用既有 `data/geography/*.json` 体系；确需新增坐标时逐条登记来源，不允许凭记忆填经纬度。
