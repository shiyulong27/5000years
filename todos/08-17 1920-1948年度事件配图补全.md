## 一、背景

1920-1948 年的中国与世界事件文字和年份页已经完整，但配图不完整。原会话尝试用 Wikimedia/Wikipedia 自动检索补图，出现同名事件、纪念设施、后世宣传照、现代地图和无关实物误配。任务跨越 290 条事件，且每张图片均需核对内容、来源和许可，因此需要可恢复的长期进度档案。

## 二、目的

为 1920-1948 年事件补充可追溯、可复用且与事件直接相关的图片；无法找到可靠图片时保留无图，不以低质量或误导图片凑齐数量。

## 三、成功标准

- 1920-1948 年每个事件都有经人工核验的合适图片，或明确记录保持无图的原因。
- 新增图片具有原始页面、作者或机构、许可信息和准确图注；非现场资料图在图注中明确说明。
- 两份 YAML 可解析，图片本地路径存在，未出现重复文件、错误年代、纪念设施冒充现场或中文编码污染。
- `npm run validate` 和相关测试通过；禁止执行 `npm run build`。

## 四、范围

### 不包含

- 未明确授权复用的新闻网站版权图片；新闻图片仅可作内容核验。
- 提交 Git、发布或执行 `npm run build`。

- 本轮新增并核验的世界事件图片包括：国联 1927 年合影、列宁 1920 年肖像、麦克劳德资料照、英埃战争历史图、苏联成立条约封面、洛桑条约边界图、啤酒馆政变同期照片、1923 伦滕马克实物、废除哈里发制度同期报纸、《超现实主义宣言》初版、巴尔托与驯犬员、《我的奋斗》初版。
- `data/events/minguo.yaml` 与 `data/world/modern.yaml` 均为 UTF-8 无 BOM、LF 换行。

### 基于证据的判断

- 纯自动检索无法满足质量要求；宽泛关键词会稳定产生同名、后世或纪念类误配。
- 条约原文、法令、同时代报纸、货币实物、战役地图和明确同期照片可作为资料图，但图注必须说明是否为现场。
- 中国近现代事件同名或相近事件更多，应比世界事件采用更严格的人工候选表。

### 尚未验证的假设

- 剩余多数事件可在 Wikimedia Commons 找到可复用候选；需要逐条验证，不能作为完成事实。
- BBC 成立、迪士尼成立、土耳其共和国成立、英国首届工党政府等难例可能只能使用人物或机构背景图；需进一步权衡是否足够相关。

### 未决问题

- 是否接受与事件高度相关但非现场的领导人肖像、机构设备或稍晚年份资料照。目前原则是可以，但必须明确图注且不得误导。
- 无可复用图片的事件是否允许长期保持无图。按 reviewer 规则允许，需记录原因。

## 六、约束与原则

- 优先 Wikimedia Commons、Wikipedia 条目主图和明确可复用的权威机构图片。
- 新华网及新闻网站图片可用于核验；没有明确复用许可不得下载进仓库。
- 每次不超过 5 个网络候选，单请求超时建议 3-6 秒，避免连续无反馈超过 60 秒。
- 自动脚本只作候选发现和精确写入；写入前必须人工审阅候选文件名、年代、内容和许可。
- 保护工作树中大量与本任务无关的未提交改动，不得整文件回退 `data/world/modern.yaml`。
- 使用最小补丁；修改后检查 `git diff`、编码、换行和中文可读性。
