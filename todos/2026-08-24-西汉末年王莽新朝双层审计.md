项目已完成固定版本《上下五千年》第 64–72 篇“晁错削地”至“王昭君出塞”的审计；第 73 篇“王莽复古改制”被作为下一阶段边界。当前 Skill 已补强为两层流程：书目篇目覆盖与独立朝代完整性审计必须分开完成。历史会话保存了同一 1988 年版第 73–76 篇的连续目录输出，但书目 API 当前返回 400，需保留历史证据并如实记录当前外部状态。

## 二、目的

确定西汉末年、王莽新朝及其通向东汉初年的范围边界，分别评估书目篇目承载和朝代结构性内容完整性，形成有来源、有争议边界、可继续修订的候选清单。

## 三、方案

### 推荐方案

先固定可复核的同版目录范围，再用项目加载器建立当前数据基线；书目层覆盖第 73 篇及紧邻的 74–76 篇，朝代层独立检查西汉末年、新朝和东汉建立过渡所需的政权沿革、制度、战争、社会与代表人物。审计阶段保持只读，只有用户后续明确授权才修改 YAML。

### 方案步骤

1. 记录 1988 年版第 73–76 篇目录、来源日志位置、当前 API 失败状态和项目分期边界。
2. 用 `loadAll('./data')` 按日期、文件归属、`related_dynasties` 和实体关系建立西汉末年/新朝/东汉初年基线。
3. 分别完成书目逐篇映射和独立朝代完整性维度审计，列出高、中、低优先级缺口及史料核验入口。
4. 仅在用户授权后做最小数据修订、定向测试、验证和报告收尾。

### 备选方案与取舍

- 只审计第 73 篇：范围更小，但会割裂王莽改制与绿林赤眉、昆阳、刘秀重建汉王朝的连续过渡，不能满足本 Skill 的时期完整性要求。
